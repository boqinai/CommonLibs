# Changelog

## 0.1.0

- Add shared light and dark semantic color tokens.
- Add immutable, strongly typed color groups with application overrides.
- Add WCAG contrast ratio helpers.
- Reject non-sRGB colors in contrast helpers.
- Add a required, readable `onBase` brand-fill foreground and document safe brand, soft-action, and raised-surface pairings.
- Use the reviewed translucent default shadow colors.
- Expand contrast and palette regression coverage.
